Salaries Analysis
This project analyzes public salary datasets to explore patterns, trends, and anomalies in compensation.
The workflow includes data cleaning, handling missing values, and removing duplicates to ensure data quality.
Key salary components such as BasePay, OvertimePay, and OtherPay were converted to numeric types for better analysis, and exploratory data analysis (EDA) was conducted through visualizations like histograms, box plots, and strip plots to identify distributions, outliers, and skewness. 
This project provides a foundation for deeper statistical insights and potential predictive modeling related to salaries.
